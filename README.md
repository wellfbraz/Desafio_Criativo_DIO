# Desafio2-DIO
Desafio Criativo: Os 15 Melhores RPGs de Mesa para Divulgação e Engajamento.

## Visão Geral do Levantamento

O levantamento apresenta um recorte bastante diversificado do mercado de RPG de mesa, reunindo:

- Fantasia medieval;
- Terror;
- Ficção científica;
- Cyberpunk;
- Faroeste sobrenatural;
- Sistemas genéricos.

O artigo destaca tanto títulos clássicos quanto sistemas modernos e independentes, evidenciando que o hobby está em constante renovação e possui opções para praticamente todos os perfis de jogadores.
